How we work

Glossary

The vocabulary this wiki uses. Spagitty's own terms first, then the git ones it leans on — because the rule in the interface is standard git terminology only, and that only helps if the terms are defined somewhere.

Spagitty's own terms

AgentA coding assistant with a command line, installed on your machine — Claude Code, Codex, Cursor, Oh My Pi, or one you configure yourself. Spagitty runs agents; it does not contain them.
Agent farmA goal, the tasks it was cut into, and the agents working them in parallel. See the agent farm.
Autonomy levelWhere you stand in the loop, from Manual (nothing runs by itself) to Unattended. Five settings, each a sentence rather than a slider.
BadgeAn achievement in the delight layer, earned per repository and per actor. Never awarded for time spent in the application.
The bedThe lane column's background, laid out once at the full height of the table underneath the rows — what a repository shorter than the window needs so the column does not simply end at the last commit.
Delight layerBadges, titles, cards and sounds. Deliberately a sink: git actions push events into it and it pushes nothing back.
Divergence barThe two-sided bar on the Branches screen showing ahead and behind, scaled against the widest drift on screen. It replaced ↑2 ↓3, which read worst in exactly the case that matters.
First-pass rateHow often an agent's work passed verification and review without being sent back. The only thing agents are ranked by — volume ranks whoever was given the most work.
ForgeA repository host: GitHub, GitLab or Bitbucket Cloud. Kept host-agnostic in the interface, with a test that fails if a host's name appears in a screen.
Glass / the lensThe frosted, refracting chrome. The filter is applied to the application underneath a pane rather than to the pane itself, because the usual web technique renders nothing on WebKitGTK.
HandoffThe structured thing an agent returns at the end of a run — status, a test report, proposed tasks — alongside its prose.
HoldA control in the farm's log drawer that freezes the list so a line can be read while it is still arriving, and counts what arrived meanwhile. Distinct from following, which is just where the scrollbar is.
LeaseA path-level claim a task holds while it runs. Worktrees stop two agents corrupting each other's files; leases stop two of them editing the same path.
PortraitThe author avatar drawn on a commit node, generated from the email address and never fetched — so it is the same on every machine, and an offline repository looks no different from an online one.
Root setWhat a visibility control resolves to: the tips a fresh walk starts from. Never a filter over rows already drawn, which would leave lanes drawing edges between commits that are not parent and child.
Screen codeThe short handle for a screen — 1A, 1H, 1Q — so it can be named in one token. See the screen reference.
SweepA manual test pass against the fixture repository, recorded as filled-in results in the work item's own document.
TaskThe farm's unit of work: machine-readable, with a kind, dependencies, expected paths and its own verification commands.
VerificationRunning the repository's own commands against an agent's work, in that task's worktree. The gate between “the agent says it is done” and “it is done”.
Work itemA FEAT-###, TASK-### or BUG-### under agile/, with its plan and test documents. The join key between a branch, a commit and the record.
Working recordThe agile/ directory as a whole — why a change existed, what was verified, and what broke along the way.

Git terms, as Spagitty uses them

Ahead / behindHow many commits a branch has that its upstream does not, and vice versa. Counted against the remote-tracking ref on disk, so the numbers are as old as the last fetch — and Spagitty says how old rather than implying they are live.
Annotated tagA tag that is its own object and can carry a message. A lightweight tag is just a ref. The difference decides whether a message can exist at all, so the two are told apart throughout.
BlameWhich commit last touched each line of a file.
Cherry-pickApplying one commit's change onto another branch, producing a new commit.
Detached HEADHEAD pointing at a commit rather than a branch. Reachable deliberately from the graph, and recoverable through the reflog.
Fast-forwardMoving a branch pointer forward when there is nothing to merge, because the target already contains it.
HunkA contiguous block of changed lines in a diff, with its context. Spagitty stages, unstages and discards by hunk as well as by file.
Index (the staging area)What the next commit will contain. During a conflict it holds all three versions of a file — stage 1 the base, stage 2 ours, stage 3 theirs — which is the whole data model of the Conflicts screen.
LaneA vertical column in the commit graph. A branch's line of development as drawn, not as named.
Ours / theirsThe two sides of a conflict. Which is which depends on the operation, which is why Spagitty reads the operation in progress from the repository's own state rather than inferring it.
ReflogWhere a ref has been. What answers “what did I just do to this history”, and the way back from almost anything.
Rebase (interactive)Replaying a run of commits onto a new base, optionally reordering, squashing, rewording or dropping them along the way.
Remote-tracking refThe local record of where a remote branch was at the last fetch. Not the remote itself.
SquashFolding a commit into the one above it. Upward, because that is the direction git folds — a plan whose first row is a squash has nothing above it and is refused with that reason.
StashA commit whose first parent is the commit the work was made on. refs/stash's reflog is the list, and stash@{n} is literally the nth entry.
SubmoduleA repository checked out inside another at a pinned commit.
TREESAMEGit's own simplification rule for path filters: a commit whose tree matches any parent's for that path is skipped. It is what stops a merge being listed for a change it only carried across.
WorktreeAn additional working directory attached to the same repository, on its own branch. What the farm gives every task.
