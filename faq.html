FAQ

Common questions, answered plainly. If the answer is longer than a paragraph it lives on its own page and this points at it.

Using it#

What does Spagitty cost?#

Nothing. It is free software under the GPL-3.0-or-later, with no paid tier, no account and no service behind it. If you run coding agents through the farm, those agents cost whatever they cost — that is between you and their providers.

Which platforms?#

Linux, macOS and Windows. Every release builds all three. The published macOS build is Apple silicon; the draft lane also produces an Intel one. See install & first run.

Why does macOS refuse to open it?#

Nothing is code-signed — there is no Apple Developer account in this project. Right-click the app, choose Open, then Open again in the dialog. On Windows, choose More info → Run anyway. Adding real signing is tracked, not ignored.

Does it need git installed?#

Yes. Reads are answered in-process with gix, but every operation that writes goes through the git binary — deliberately, so hooks, credential helpers, LFS, submodule recursion and the sequencer all behave exactly as they would in a terminal. See the boundary.

Can I open more than one repository?#

There is a tab strip, and tabs can point at linked worktrees as well as repositories. One repository is open at a time in the backend — opening another tears down the previous walk and watcher — but switching between tabs is what you would expect.

Where did my setting go?#

Behaviour toggles, the repository list and connected accounts live in Spagitty's own configuration directory. The theme, the size dials, column layouts and badge records live in the webview's localStorage, keyed by repository path — because they have to be applied on the first frame, before any command could answer. The full table is on install & first run.

Privacy#

What does Spagitty send?#

Pull request data to the forge you connected, git's own network operations to your remotes, and an update check when you ask for one. That is the complete list, and it is enumerated on privacy & security.

Is there telemetry?#

No. No analytics, no crash reporting, no usage metrics, no account. There is nowhere for any of it to go — there is no Spagitty server.

Where does my forge token live?#

The OS keychain, and nowhere else. accounts.json holds a host and a login. A token that appears in a clone URL is stripped from the command record before the entry is stored, so it cannot leak through the copy button.

How can I check any of that?#

Two files. Exactly one HTTP client exists in the workspace, declared only in spagitty-core and reachable only from forge/http.rs; and exactly one module spawns a process, shell.rs. Both are asserted by tests. The webview links no HTTP client at all.

The agent farm#

Does Spagitty include an AI model?#

No. Nothing here performs inference and nothing ships an API key. The farm runs agents you have installed, as you, with your credentials.

Which agents does it support?#

Claude Code, Codex, Cursor and Oh My Pi are detected on PATH out of the box, and anything else with a command line can be added by hand — a configured command with a prompt token, so a new provider is a settings change rather than a release.

Can an agent break my working copy?#

No. Every task runs on its own branch in its own worktree, and nothing an agent does reaches your checkout. Path-level leases stop two agents editing the same file, and deleting a task keeps the commits on its branch.

Can an agent merge its own work?#

Only at the top of the autonomy dial, and even then only with passing checks, a successful review by a different agent of the work actually committed, and merge permission. There is no path in the code from an agent's own report of success to Done.

What if nothing is configured to verify the work?#

The task says so, in those words, when it reaches review. It does not read as verified. “Nothing checked it” is a distinct state from “it passed”.

What if an agent goes quiet?#

After six minutes without a word, the chip and the row say how long it has been silent and the pulse stops. Nothing is killed for you — a model may think for a long time, and killing it throws the work away.

What happens if Spagitty crashes mid-farm?#

The farm is written to disk after every state change, by rename, with an append-only event log. On restart the service reconciles what is on disk against the worktrees that actually exist, and sweep removes what a crashed run left behind.

Comparisons#

How is this different from the Git client I already use?#

In three ways that matter. It is local-first with no account, and the claim is narrow enough to be checked rather than trusted. It treats agents as first-class actors — credited separately, ranked by first-pass rate, and now run from inside the client. And it is meant to be read: the reasoning behind each decision is in the repository, not in someone's head.

What it deliberately does not do is also written down: no dragging commits in the graph, no inline message editing, no manual lane layout, no independent graph zoom.

Is it a GitHub client?#

It is a Git client that can talk to GitHub, GitLab and Bitbucket Cloud when you connect an account. The Pull requests screen is the only screen whose data comes off the network; everything else reads the disk, and Spagitty works fully offline without any account at all.

Is the farm a CI system?#

No. Verification runs your repository's commands locally, in a task's worktree, as a gate before a merge. It is not a pipeline, it does not run on push, and it replaces nothing you already have.

Contributing and licensing#

Can I use Spagitty commercially?#

Yes, within the terms of the GPL-3.0-or-later. If you distribute a modified version, the licence requires you to make the corresponding source available under the same terms. The About section carries the exact commit a build came from, for exactly that reason.

How do I contribute?#

Start with contributing. In short: sign off your commits, name your branch after a work item, update the docs your change affects in the same commit, add a changelog entry, and clear gates 1 to 3 locally.

Where do I report a bug?#

The issue tracker. Say which screen (by its code, if you know it), your platform and version from Settings → License, and — if a git operation is involved — what the command drawer recorded, since that shows the actual argv rather than a reconstruction.
